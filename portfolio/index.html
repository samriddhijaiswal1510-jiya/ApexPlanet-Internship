The Journey

Internship Timeline

60 days · 5 tasks · complete data analytics lifecycle

22 May 2026

🚀 Internship Begins

Joined ApexPlanet Software Pvt. Ltd. as a Data Analytics Intern. Onboarding, goal setting, and dataset exploration.

Week 1

Task 1 — Data Immersion & Wrangling

Understanding datasets, cleaning, transformations, and feature engineering.

  • Diagnosed raw Amazon product data (1,465 records × 16 columns)
  • Removed duplicates and filled missing rating_count values
  • Stripped currency symbols, converted data types
  • Engineered 9 new features (savings, discount_tier, price_segment, etc.)
  • Applied IQR-based outlier detection
Pandas Data Cleaning Feature Engineering
Week 2–3

Task 2 — EDA & Business Intelligence

Descriptive statistics, SQL queries, visualizations, and actionable insights.

  • Answered 9 business questions using SQL on SQLite database
  • Built multi-table JOINs splitting data into orders and order_items schemas
  • Created correlation heatmap, scatter plot, pair plot, monthly trend charts
  • Key Insight: West region generates highest revenue; Technology is top category
EDA SQL Seaborn Business Intelligence
Week 4

Task 3 — Deep-Dive Analysis & Interactive Dashboarding

KPI definition, business problem selection, and Power BI dashboard design.

  • Defined 5 core KPIs: Total Sales ($2.25M), Orders (4,916), Avg Order Value ($458), Customers (793), Products (1,850+)
  • Built interactive Power BI dashboard with regional, segment, and category breakdowns
  • Identified top-performing products and shipping mode efficiency
Power BI KPIs Dashboard Analytics
Week 5–6

Task 4 — Data Storytelling & Statistical Validation

Business presentation, hypothesis testing, and actionable recommendations.

  • Applied Welch's Two-Sample T-Test (scipy.stats) comparing Technology vs Furniture sales
  • Defined H₀ (no difference) vs H₁ (significant difference) and interpreted results
  • Delivered a business-ready presentation with statistical validation
Storytelling Statistics Hypothesis Testing Presentation
Week 7–8

Task 5 — Capstone Integration & Portfolio

Full portfolio website, GitHub repository, documentation, and personal branding.

  • Consolidated all 5 tasks into a master portfolio repository
  • Built this premium portfolio website with HTML, CSS, and JavaScript
  • Wrote comprehensive READMEs and documented key learnings
  • Finalized GitHub repository structure for public showcase
Portfolio Documentation GitHub Presentation
19 July 2026
