# Sales Dashboard

## Objective
Build an interactive sales dashboard using Power BI.

## KPIs
- Total Sales
- Total Orders
- Average Order Value
- Total Customers
- Total Products

## Visualizations
- Sales by Region
- Sales by Segment
- Sales by Category
- Sales Trend Over Time
- Top Products by Sales

## Tools Used
- Python (Pandas)
- Power BI

## Dataset
Superstore Sales Dataset
