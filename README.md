## 📌 Task Overview

### ✅ Task 1 — Data Cleaning & Preprocessing
**Timeline:** 7 Days

**What I did:**
- Cleaned and preprocessed the Amazon Product Sales dataset
- Handled missing values, duplicates, and data type inconsistencies
- Engineered new features (category hierarchy, price buckets, discount tiers)
- Exported a clean, analysis-ready CSV

**Key Files:**
- `data_cleaning.py` — Full cleaning pipeline
- `clean_amazon.csv` — Cleaned dataset
- `data_dictionary.csv` — Column definitions and metadata

### ✅ Task 2 — Exploratory Data Analysis (EDA) & Business Intelligence
**Timeline:** 14 Days

**What I did:**
- Performed full EDA on the Superstore Sales dataset (9,800 records)
- Answered 9 business questions using SQL queries (including multi-table JOINs)
- Created multivariate visualizations: heatmap, scatter plot, pair plot, trend charts
- Built a KPI dashboard mockup

**Key Files:**
- `eda_analysis.ipynb` — Full EDA notebook
- `sales.db` — SQLite database for SQL queries
- `charts/` — All visualization PNGs
- `dashboard/superstore_dashboard_mockup.png` — Dashboard mockup

📂 [View Task 2](./Task%202/)

### ✅ Task 4 — Hypothesis Testing & Statistical Analysis
**Timeline:** 7 Days

- Conducted Welch's Two-Sample T-Test on Superstore Sales data
- Tested whether Technology and Furniture categories have significantly different average sales
- Documented results with T-Statistic, P-Value, and conclusion in a PDF report

**Key Files:**
- `hypothesis_test.py` — Python T-Test script
- `Task4_Sales_Analysis_Hypothesis_Testing..pdf` — Full statistical report

## 📊 Key Learnings

- Real-world data is messy — cleaning is 60% of the work
- SQL JOINs and aggregations are essential for business questions
- Visualizations must tell a story, not just show numbers
- Statistical significance ≠ practical significance
- A well-documented GitHub repo is as important as the code itself
