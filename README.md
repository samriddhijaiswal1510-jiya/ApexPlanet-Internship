## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Premium Design** | Dark glassmorphism theme with purple-cyan gradient palette |
| 🌊 **Particle Background** | Animated canvas-based particle network |
| ⌨️ **Typing Animation** | Rotating skills with typewriter effect |
| 📊 **Animated Counters** | Scroll-triggered number animations |
| 📜 **Scroll Reveal** | Intersection Observer-based entrance animations |
| 🧲 **Mouse Lighting** | Card-level mouse-follow glow effect |
| 🔢 **Skill Bars** | Animated progress bars for technical skills |
| 📅 **Expandable Timeline** | Clickable internship timeline with detail panels |
| 🖼️ **Gallery + Lightbox** | Project screenshots with lightbox viewer |
| 📱 **Fully Responsive** | Desktop · Laptop · Tablet · Mobile |
| ♿ **Accessible** | ARIA labels, keyboard navigation, semantic HTML |
| ⚡ **Performance** | Lazy loading, requestIdleCallback, RAF optimizations |

## 📦 Adding Your Assets

1. **Resume** → Place `resume.pdf` in `assets/resume/`
2. **Certificates** → Place PDFs in `assets/certificates/`
3. **Profile Image** → Place in `assets/images/`
4. **Update links** in `index.html` → search for `saayan@example.com` and `https://linkedin.com` and replace with real values
