# Key Learnings & Technical Skills
## ApexPlanet Data Analyst Internship

---

## Technical Skills Developed

### Python & Data Manipulation
- Used **Pandas** extensively for data loading, cleaning, transformation, and aggregation
- Applied feature engineering techniques (label encoding, bucketing, hierarchy extraction)
- Worked with datetime parsing, period grouping, and time-series analysis

### SQL & Business Intelligence
- Wrote **9+ SQL queries** using SQLite to answer real business questions
- Used aggregations (`SUM`, `COUNT`, `AVG`), filtering (`WHERE`, `GROUP BY`, `ORDER BY`)
- Performed **multi-table JOINs** splitting data into `orders` and `order_items` tables

### Data Visualization
- Created bar charts, histograms, scatter plots, heatmaps, pair plots, line charts
- Used **Matplotlib** and **Seaborn** for publication-quality visuals
- Built an interactive **Power BI dashboard** with KPI cards and drill-down visuals

### Statistical Analysis
- Applied **Welch's Two-Sample T-Test** (`scipy.stats.ttest_ind`)
- Interpreted T-Statistic and P-Value for business conclusions
- Understood the difference between statistical and practical significance

### Version Control & Documentation
- Used **Git** and **GitHub** for version control throughout the internship
- Wrote professional **Markdown README files** for every task
- Maintained clean commit history with descriptive messages

## Personal Reflections

### What Went Well
- Structured approach to each task — plan, code, document, push
- Consistent use of GitHub kept work organized and shareable
- SQL queries gave clear, quantifiable answers to business questions

### What I Would Do Differently
- Start documentation earlier instead of at the end
- Add more advanced visualizations (Plotly interactive charts)
- Explore machine learning for predictive sales analysis

### Most Valuable Skill Gained
**SQL + Python combination** — being able to pull data with SQL and then
visualize/analyze it with Python is an extremely powerful and practical skill
for any data analyst role.
